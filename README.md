# frontend-css-platzi

Ejercicios del curso de CSS de Platzi: maquetación de pantallas de login con HTML y CSS usando Grid y Flexbox.

![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)
![Platzi](https://img.shields.io/badge/Platzi-98CA3F?style=for-the-badge&logo=platzi&logoColor=white)

## Contexto

Repositorio con prácticas del curso de CSS de Platzi. Son pantallas sueltas de un flujo de login (estilo Yard Sale) hechas con HTML + CSS para reforzar layout con Grid, Flexbox, media queries y tipografía con Google Fonts (Quicksand).

Cada `claseN.html` tiene su CSS embebido dentro de una etiqueta `<style>`, tal como se construye en las clases del curso.

## Tecnologías

- HTML5
- CSS3 (Grid, Flexbox, custom properties, media queries)
- Google Fonts — Quicksand
- Assets SVG (logos e iconos)

## Cómo abrir

No requiere servidor ni build. Basta con abrir cualquiera de los archivos HTML en el navegador:

- Doble click sobre el archivo `.html`, o
- Con la extensión **Live Server** de VS Code para ver cambios en caliente.

## Estructura

```
frontend-css-platzi/
├── index.html       # base con variables CSS y fuente Quicksand (body vacío)
├── clase1.html      # pantalla "Create a new password" (Grid + form)
├── clase2.html      # pantalla "Email has been sent!" (confirmación)
├── clase3.html      # pantalla de login con email y password
├── logos/           # logo Yard Sale en SVG
└── icons/           # iconos SVG (email, etc.)
```
